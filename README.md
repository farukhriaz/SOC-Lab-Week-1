# SOC Lab - Week 1

## Overview

This repository contains the practical work completed during **Week 1** of my Cyber Security Internship at **CYBERSTER**.

The objective of this lab was to build a virtual Security Operations Center (SOC) environment, configure network communication between multiple systems, deploy Wazuh SIEM, monitor endpoint activity, and perform basic threat detection using real security tools.

---

## Lab Environment

- Wazuh Ova
- Kali Linux
- Windows 11
- VMware Workstation

## Key Features

- Built a virtual SOC environment using VMware Workstation.
- Configured Ubuntu Server as the Wazuh Manager.
- Connected Windows 11 and Kali Linux as monitored endpoints.
- Captured and analyzed network traffic with Wireshark.
- Performed reconnaissance using Nmap.
- Monitored endpoint events through Wazuh SIEM.
- Investigated alerts using the Threat Hunting module.
- Correlated detected events with the MITRE ATT&CK Framework.
